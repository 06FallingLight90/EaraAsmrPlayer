## 踩坑记录

每条按「现象 → 根因 → 解法」记录，解法均已验证。

### 1. Gradle 发行版下载失败（wrapper 阶段）

- **现象**：`gradlew help` 在 `Install.forceFetch` 抛 HTTPS 连接异常。
- **根因**：系统代理配置指向 `127.0.0.1:7890` 但无代理进程运行；部分下载路径经代理转发失败。curl 直连正常。
- **解法**：curl 直连下载 zip，手动播种到 wrapper 缓存目录（目录名 = URL 的 MD5 转 base36，gradle-8.6-bin 为 `afr5mpiioh2wthjmwnkmdsd5w`），wrapper 检测到 zip 后自行解压。

### 2. 构建失败且错误信息只有 "25"

- **现象**：daemon 启动后立即失败，`What went wrong:` 后只有 `25`。
- **根因**：PowerShell `Set-Content` 给 gradle.properties 写入了 **UTF-8 BOM**（`EF BB BF`），Java Properties 把首个键名读成 `\uFEFForg.gradle.java.home`，配置静默失效 → daemon 落到系统默认 JDK 25 → AGP 拒绝。错误信息 "25" 即 Java 版本号。
- **解法**：用无 BOM 方式写文件（Write 工具，或 `[IO.File]::WriteAllText` + `UTF8Encoding($false)`）。**教训：Windows PowerShell 写配置文件必须校验 BOM。**

### 3. transforms 缓存移动失败（连续复现）

- **现象**：`:app:checkDebugAarMetadata` 报多个 `Could not move temporary workspace ... to immutable location`；清缓存重建无效。
- **根因**：项目内 `.gradle-user-home` 位于 Trae 工作区，构建期间数千个新建缓存文件被文件监视器 / Defender（MsMpEng）占用句柄，打断 Gradle 的原子重命名。
- **解法**：构建时加 `-g "C:\Users\24131\.gradle"` 把 Gradle 主目录迁出工作区（短路径 + 无监视器）。原项目内缓存保留不用。

### 4. 依赖下载报裸域名（UnknownHostException）

- **现象**：`kspDebugKotlin` 阶段 `Could not GET 'https://repo.maven.apache.org/...' > repo.maven.apache.org`。
- **根因**：并发下载时的瞬时 DNS 抖动（此刻 curl 直连 Maven Central 正常）。
- **解法**：直接重试构建即通过。若频繁复现：在 `C:\Users\24131\.gradle\init.d\` 加 Aliyun 镜像 init 脚本（机器级配置，不入库）。

### 5. 实机安装被拒（INSTALL_FAILED_USER_RESTRICTED）

- **现象**：`adb install` 报 `Failure [INSTALL_FAILED_USER_RESTRICTED: Install canceled by user]`。
- **根因**：小米 HyperOS 的 USB 安装限制。
- **解法**：手机端 开发者选项 → 开启「USB 安装」（需登录小米账号），安装时留意手机弹窗确认。

## 常用命令

```powershell
# 构建 Debug APK（-g 指向工作区外的 Gradle 主目录，规避坑 3）
.\gradlew-local.bat -g "C:\Users\24131\.gradle" :app:assembleDebug

# 构建并安装到实机（一步到位）
.\gradlew-local.bat -g "C:\Users\24131\.gradle" :app:installDebug

# 启动应用
adb shell monkey -p com.asmr.player -c android.intent.category.LAUNCHER 1

# 前台 Activity 验证
adb shell "dumpsys activity activities | grep -E 'topResumedActivity'"

# 应用运行日志
adb logcat --pid=$(adb shell pidof com.asmr.player)
```

注：`adb` 未加入 PATH 时，完整路径为 `D:\Software\Android\Sdk\platform-tools\adb.exe`。
